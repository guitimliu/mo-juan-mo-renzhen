# POC 介面規格（各階段之間的 JSON 契約）

所有階段以 JSON 交換，任何人可以用假資料先跑自己那段。**先凍結這份，再各自開工。**

## S0 前端 → 協調器
POST /cases　multipart：petition_image（訴願書）、disposition_image（處分書）
回傳：{ "case_id": "poc-001" }
GET /cases/{case_id}　回傳下列所有階段的最新狀態（前端輪詢即可，不需 websocket）
